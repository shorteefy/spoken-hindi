# Notice

## Structure

The layout of this project follows the
[simplified-technical-english](https://github.com/0xpili/simplified-technical-english)
skill by 0xpili, which is released under the MIT License. That layout is:

- SKILL.md
- references/ for the writing rules, word list, and substitutions
- examples/
- a standard-library checker script

No text, word list, or code was copied from that project.

## Simplified Technical English

Simplified Technical English is defined by the ASD-STE100 specification. The
specification and its dictionary are the property of ASD (AeroSpace, Security and
Defence Industries Association of Europe). You can get the specification free of
charge from https://www.asd-ste100.org.

This project uses STE only as a model: a controlled vocabulary, numbered writing
rules, and limits on sentence and paragraph length. It does not reproduce the STE
dictionary or the STE rule text. The Hindi word list, the substitutions, and the rules
are original work.

This project is not an ASD document and is not endorsed by ASD.
